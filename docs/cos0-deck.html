The thesis

One wire format. Every model, every provider.

  • The client talks only OpenAI Chat Completions to the backend.
  • The backend routes each request by model id and normalizes every provider back to that format.
  • Keys, auth, rate limits and billing live in one control point — the server.
  • The client carries nothing but a single ada key. Same shape as Cursor.

The engine

Stream → call tools → feed back → repeat, until done.

  • Each turn streams the model's reply; tool calls are gated by the permission mode, run, and appended as tool turns.
  • read/write/edit_file · apply_patch · bash in a real PTY · grep/glob · web · lsp_diagnostics · ask_user
  • Auto-format on edit (prettier / gofmt / ruff / shfmt) in trusted projects.
  • Ollama leaked a tool call as JSON text? Detected and run anyway.
Safety

Three modes. Every approval in plain words.

/ask · default

Each gated tool prompts — “ada wants to run a shell command…” — and one key answers: [y]es · [a]uto · [p]lan · [n]o.

/plan · read-only

ada plans but won't edit. /run approves and executes.

/auto · free run

Tools run without asking; destructive bash still confirms.

protected paths

Undo reverts the agent's edits; snapshots capture the whole tree.

Skills

~285 skills that actually fire.

  • Bundled SKILL.md instructions across ~30 categories — loaded only when a task needs them.
  • A relevance router ranks every request: a clear match is auto-applied (↳ skill: commit); ambiguous ones are suggested.
  • Browse with list_skills, rank with find_skill, load with use_skill.
  • Add your own under .ada/skills/<name>/ — front-matter is all it takes. Project overrides global overrides built-in.
Trust

Nothing is ever lost.

sessions

Every turn persisted as append-only JSONL; --continue / --resume picks up where you left off.

undo

/undo reverts the agent's edits; checkpoints make it surgical.

snapshots

/snapshot + /restore capture the whole workspace tree.

compaction

Old turns are summarized automatically as context grows — /compact forces it, /context shows the estimate.

Enterprise control plane

Your org, one backend.

seats & policy

Per-user seat keys; server-enforced model allowlist + tool rules pushed to every client.

metering & audit

Per-user usage metering and an append-only audit log. File-backed, self-hosted in your network.

OIDC SSO

Okta, Entra, Auth0, Keycloak, Google Workspace. JIT-provisioned seats; offboarding is immediate.

fail-closed

Stdlib-only RS256/JWKS verification, no new dependency — a bad token is a denied request.

Deploy

Ship it anywhere.

  • docker compose up runs the backend; clients point at it with ADA_BACKEND_URL.
  • Cloudflare Workers AI (@cf/*) or an AI Gateway — zero code change.
  • No build step: TypeScript runs straight through tsx; one native dep (node-pty).
  • Sign in with GitHub or Google (RFC 8628 device flow) — zero client config, no password ever reaches ada.
